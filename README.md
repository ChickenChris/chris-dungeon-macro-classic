# Chris's Dungeon Macro - Classic (free)

AutoHotkey v2 macro that farms dungeons in Anime Adventures (Roblox).

## Install
1. Install AutoHotkey v2 from autohotkey.com.
2. Download this as a zip (green **Code** button > **Download ZIP**) and unzip it.
3. Run `Chris's Dungeon Macro.ahk`.

## Game settings needed
- Show Upgrade UI on left: **ON**
- Disable Auto-Open Upgrade UI: **OFF**
- Windows display scale: **100%**

## Updating
Close the macro and double-click **Update.bat**. Your Settings and Logs are kept.
